# 業績計算工具（Count Shipping Subtotal）

## 功能說明

讀取出貨訂單 CSV，**依日期**計算各通路（宅配、7-11、全家）的業績、訂單數、雙數，並扣除退貨。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/count-shipping-subtotal
2. （選用）上傳**既有統計報表**（前次匯出的 Excel）
3. 上傳**新的訂單 CSV**（可多檔）
4. 系統依通路分類並計算業績
5. 點擊**下載**取得統計報表

## 輸入檔案格式

- 格式：CSV
- 通路分類方式同每日出貨合併工具（依 `Tags` 欄位：宅配 / 全家 / 7-11；判不出的歸「未分類」）
- 以 `Name`（母單號碼）分組，母單決定通路與退貨狀態

## 業績計算說明

- 依**日期**彙總各通路的業績、訂單數、雙數，並區分有／無運費
- 退貨訂單另計 `退貨訂單數`、`退貨總雙數`、`退貨業績`

## 輸出格式

Excel，分頁如下：

- 各通路分頁：`宅配`、`7-11`、`全家`（保留原始訂單列）
- `未分類`（僅在有無法分類的訂單時產生）
- `統計`：欄位為
  `日期｜總業績｜總訂單數｜總雙數｜退貨訂單數｜退貨總雙數｜退貨業績｜` 後接各通路的
  `有運費｜無運費｜總雙數｜業績｜平均金額`（宅配、7-11、全家各一組）

## 注意事項

- 退貨資料須包含在上傳的 CSV 中，系統依母單狀態自動識別
