# 庫存表工具（Excel Merge Tool）

## 功能說明

將含有多個倉庫區塊的 Excel 庫存來源檔，整併成一份制式格式的庫存表。

> 本工具**不需要上傳模板**，輸出欄位已固定寫在程式中（頁面上的「輸出格式（制式模板）」區塊即為範例）。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/excel-merge-tool
2. 上傳**來源檔**（含各倉庫資料的 Excel，副檔名 `.xlsx`）
   - **可一次選多個檔案，也可以分次上傳累加**。典型用法：主庫存檔（總倉／電商倉／平台總倉）＋ 展威檔各一份。
   - 同檔名只會收一次，重複選到會跳過並提示，避免同一份庫存被加兩次。上傳清單可逐檔「移除」。
3. 系統自動辨識每個檔案裡的倉庫區塊（總倉 / 官網 / 平台 / 展威），可點「預覽表格」確認辨識結果
4. 點擊**產生庫存表**
5. 點擊**匯出Excel**
   - 單檔：`庫存表_<來源檔名>_<YYMMDD>.xlsx`
   - 多檔：`庫存表_合併<N>檔_<YYMMDD>.xlsx`

## 來源檔格式說明

- 只讀取第一個工作表。
- 來源檔是「商品各倉庫存數量查詢」報表，統計方式為**倉庫分頁**：每個倉庫一段，開頭是 `倉庫 :<倉庫名稱>`，接著是欄位名稱列，然後資料列，最後一列是 `數量小計`。
- 區塊類型依**倉庫名稱**判斷，順序如下（先命中先算）：

  | 倉庫名稱含 | 歸類 | 實際例子 |
  |---|---|---|
  | 展威 | 展威 | 展威麗嬰房(平台總倉)、展威麗嬰房 |
  | 平台 / 平臺 | 平台 | 展宇麗嬰(平台總倉) |
  | 電商 / 官網 | 官網 | 展宇麗嬰(哈瓦仕電商倉) |
  | 其他（未知） | 總倉 | 展宇麗嬰房總倉 |

  順序不可調換：「展威麗嬰房(平台總倉)」同時含「平台」與「總倉」，不先攔會被判成平台；「展宇麗嬰(平台總倉)」也同時含「平台」與「總倉」，要判成平台而不是總倉。
- 標題列之後、含「商品代號」「商品名稱」的那列視為欄位名稱列，其後的資料列才會被讀取。
- 含「小計」「合計」「數量」的列視為統計列，不計入資料。

## 來源欄位對應

| 來源欄 | 用途 |
|---|---|
| A | 商品代號 |
| B | 商品名稱 |
| L | 可售量（依區塊填入 總倉／官網／平台／展威） |
| M | 含稅定價 |
| N | 年度 |
| P | 尺寸名稱 |

## 輸出格式

單一 Excel，分頁名稱 `庫存匯總`，欄位順序：

`商品代號｜商品名稱｜貨號｜尺寸名稱｜年度｜含稅定價｜總倉｜官網｜平台｜展威｜備註`

- **貨號**：商品代號需剛好含 **2 個 `-`** 才產生；`SG` 開頭取前 12 字，其餘取前 13 字；不符則留白。
- **數量為 0 時留白**（與紙本庫存表格式一致）。
- **備註**：一律留白，供人工填寫。
- 排序：年度**倒序**，同年度再依商品代號自然排序。

## 注意事項

- 同一個商品代號在多個區塊（含跨檔案）出現時，會合併成同一列，各倉庫數量分別填入對應欄位。
- **多個倉庫落在同一個輸出欄位時會相加**。例：「展威麗嬰房」與「展威麗嬰房(平台總倉)」都算展威，同一商品在兩邊都有庫存時，展威欄是兩者之和。
- 同一個倉庫在檔案裡重複出現（分頁）不會重複累加，以最後一次的數量為準。
- 未知倉庫類型一律歸類為**總倉**（1140922 起的規則）。
- 支援格式：`.xlsx`
