# 庫存表工具（Excel Merge Tool）

## 功能說明

將含有多個倉庫區塊的 Excel 庫存來源檔，整併成一份制式格式的庫存表。可依設定產出兩種版本：**倉庫別**（以庫別為欄位）與**品牌別**（庫別欄後多一欄「品牌」方便篩選）。

> 本工具**不需要上傳模板**，輸出欄位已固定寫在程式中（頁面上的「輸出格式」區塊即為範例）。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/excel-merge-tool
2. 上傳**來源檔**（含各倉庫資料的 Excel，副檔名 `.xlsx`）
   - **可一次選多個檔案，也可以分次上傳累加**。典型用法：主庫存檔（總倉／電商倉／平台總倉）＋ 展威檔各一份。
   - 同檔名只會收一次，重複選到會跳過並提示，避免同一份庫存被加兩次。上傳清單可逐檔「移除」。
3. 系統自動辨識每個檔案裡的倉庫區塊，可點「預覽表格」確認辨識結果
4. 在**設定面板**確認/調整對應規則，選擇**產出版本**（見下節）
5. 點擊**產生庫存表**，再點擊**匯出Excel**，檔名 `庫存表_<檔名>_<版本>_<YYMMDD>.xlsx`

## 產出版本與設定面板

背景：展宇／展威等子公司與旗下子倉（麗嬰、麗嬰房、哈瓦仕、平台…）預計合併，屆時無法只靠倉庫文字識別子倉↔子公司。因此改成「倉庫關鍵字 + 貨號」共同決定每列庫存歸屬，並可產出兩種版本。

- **倉庫別**（預設）：欄位為各庫別（總倉／官網／平台／展威／ELLE／誠品），一列一貨號。
- **品牌別**：與倉庫別完全相同，只在庫別欄後**多一欄「品牌」**。

設定面板（上傳後出現）三段，兩個版本共用：

1. **倉庫對應庫別**：自動列出偵測到的倉庫並帶入預設庫別，可用下拉調整。
2. **貨號對應庫別（覆蓋規則）**：`貨號開頭 → 庫別`，可 +/- 增減。勾「凌駕」時，該貨號開頭的商品**整列改用指定庫別**（不管來自哪個倉庫）；不勾則不生效。命中多筆取**最長前綴**。面板會列出本次檔案偵測到的貨號開頭字元。
3. **貨號對應品牌**：`貨號開頭 → 品牌名`，供品牌別版本的品牌欄使用；沒設定則品牌欄留白。

## 來源檔格式說明

- 只讀取第一個工作表。
- 來源檔是「商品各倉庫存數量查詢」報表，統計方式為**倉庫分頁**：每個倉庫一段，開頭是 `倉庫 :<倉庫名稱>`，接著是欄位名稱列，然後資料列，最後一列是 `數量小計`。
- **預設**倉庫→庫別對應，順序如下（先命中先算，可在設定面板逐倉改）：

  | 倉庫名稱含 | 歸類 | 實際例子 |
  |---|---|---|
  | 展威麗嬰房(平台總倉) | 展威 | 展威麗嬰房(平台總倉) |
  | 平台 / 平臺 | 平台 | 展宇麗嬰(平台總倉) |
  | 電商 / 官網 | 官網 | 展宇麗嬰(哈瓦仕電商倉) |
  | 其他（未知） | 總倉 | 展宇麗嬰房總倉、展威麗嬰房 |

  順序不可調換：「展威麗嬰房(平台總倉)」同時含「平台」與「總倉」，不先攔會被判成平台。
- `ELLE`、`誠品` 兩欄沒有預設倉庫規則，需在設定面板指定（倉庫對應或貨號覆蓋）才會有值。
- 標題列之後、含「商品代號」「商品名稱」的那列視為欄位名稱列，其後的資料列才會被讀取。
- 含「小計」「合計」「數量」的列視為統計列，不計入資料。

## 來源欄位對應

| 來源欄 | 用途 |
|---|---|
| A | 商品代號 |
| B | 商品名稱 |
| L | 可售量（依設定填入對應庫別欄） |
| M | 含稅定價 |
| N | 年度 |
| P | 尺寸名稱 |

## 輸出格式

單一 Excel，分頁名稱 `庫存匯總`，欄位順序：

`商品代號｜商品名稱｜貨號｜尺寸名稱｜年度｜含稅定價｜總倉｜官網｜平台｜展威｜ELLE｜誠品｜[品牌]｜備註`

- **品牌**欄只在品牌別版本出現。
- **貨號**：商品代號需剛好含 **2 個 `-`** 才產生；`SG` 開頭取前 12 字，其餘取前 13 字；不符則留白。
- **數量為 0 時留白**（與紙本庫存表格式一致）。
- **備註**：一律留白，供人工填寫。
- 排序：年度**倒序**，同年度再依商品代號自然排序。

## 注意事項

- 每列可售量落在哪個庫別欄：**有勾凌駕且貨號開頭命中的規則 > 倉庫對應**；未設定則只看倉庫對應。
- 同一個商品代號在多個區塊（含跨檔案）出現時，會合併成同一列。
- **多列落在同一個庫別欄時會相加**（例：「展威麗嬰房」與「展威麗嬰房(平台總倉)」若都歸展威）。
- 同一個倉庫在檔案裡重複出現（分頁）不會重複累加，以最後一次的數量為準。
- 支援格式：`.xlsx`
