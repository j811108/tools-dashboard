# 庫存表工具（Excel Merge Tool）

## 功能說明

將含有多個倉庫區塊的 Excel 庫存來源檔，整併成一份制式格式的庫存表。

> 本工具**不需要上傳模板**，輸出欄位已固定寫在程式中（頁面上的「輸出格式（制式模板）」區塊即為範例）。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/excel-merge-tool
2. 上傳**來源檔**（含各倉庫資料的 Excel，副檔名 `.xlsx`）
3. 系統自動辨識倉庫區塊（總倉 / 官網 / 平台 / 展威），可點「預覽表格」確認辨識結果
4. 點擊**產生庫存表**
5. 點擊**匯出Excel**，檔名為 `庫存表_<來源檔名>_<YYMMDD>.xlsx`

## 來源檔格式說明

- 只讀取第一個工作表。
- 各倉庫資料以區塊方式排列，區塊標題列含「展」「總倉」「電商」「平台」「官網」「倉庫」等關鍵字即視為新區塊的開頭。
- 區塊類型依標題列**第一格**的文字判斷，順序如下（先命中先算）：

  | 標題含 | 歸類 |
  |---|---|
  | 展威 | 展威 |
  | 平台 / 平臺 | 平台 |
  | 電商 / 官網 | 官網 |
  | 其他（未知） | 總倉 |

  「展威」必須排在最前面判斷，因為倉庫名稱「展威麗嬰房(平台總倉)」同時含有「平台」與「總倉」。
- 標題列之後、含「商品代號」「商品名稱」的那列視為欄位名稱列，其後的資料列才會被讀取。
- 含「小計」「合計」「數量」的列視為統計列，不計入資料。

## 來源欄位對應

| 來源欄 | 用途 |
|---|---|
| A | 商品代號 |
| B | 商品名稱 |
| L | 可售量（依區塊填入 總倉／官網／平台／展威） |
| M | 含稅定價 |
| N | 年度 |
| P | 尺寸名稱 |

## 輸出格式

單一 Excel，分頁名稱 `庫存匯總`，欄位順序：

`商品代號｜商品名稱｜貨號｜尺寸名稱｜年度｜含稅定價｜總倉｜官網｜平台｜展威｜備註`

- **貨號**：商品代號需剛好含 **2 個 `-`** 才產生；`SG` 開頭取前 12 字，其餘取前 13 字；不符則留白。
- **數量為 0 時留白**（與紙本庫存表格式一致）。
- **備註**：一律留白，供人工填寫。
- 排序：年度**倒序**，同年度再依商品代號自然排序。

## 注意事項

- 同一個商品代號在多個區塊出現時，會合併成同一列，各倉庫數量分別填入對應欄位。
- 未知倉庫類型一律歸類為**總倉**（1140922 起的規則）。
- 支援格式：`.xlsx`
