# 月出貨統計工具（Month Shipping Count）

## 功能說明

統計每月各通路出貨量，累積至統一的月份統計報表。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/month-shipping-count
2. （選用）上傳**既有月份統計報表**（前次匯出的 Excel）
3. 上傳**新的訂單 CSV**
4. 系統自動統計各月份出貨量
5. 點擊**下載**取得更新後的統計報表

## 輸入檔案格式

- 格式：CSV
- 日期欄位用於判斷月份歸屬

## 輸出格式

- Excel，含「月份統計」分頁
- 依月份排列，各通路出貨量並列顯示

## 注意事項

- 上傳既有報表可累積歷史資料，避免重新計算
