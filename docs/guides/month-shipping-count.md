# 月出貨統計工具（Month Shipping Count）

## 功能說明

按**月份**統計業績（不分通路），並計算 AUP、UPT、AOV 等指標，可累積至既有的月份統計報表。

## 使用步驟

1. 開啟工具：https://j811108.github.io/tools-dashboard/month-shipping-count
2. （選用）上傳**既有月份統計報表**（前次匯出的 Excel，需含 `月份統計` 分頁）
3. 上傳**新的訂單 CSV**
4. 系統自動統計各月份業績
5. 點擊**下載**取得更新後的統計報表，檔名 `月份業績統計_<YYYY-MM-DD>.xlsx`

## 輸入檔案格式

- 格式：CSV
- 日期欄位用於判斷月份歸屬
- 統計方式**不區分來源通路**

## 輸出格式

Excel，分頁 `月份統計`，欄位：

`月份｜總業績｜總訂單數｜總雙數｜淨業績｜淨訂單數｜淨雙數｜退貨訂單數｜退貨總雙數｜退貨業績｜AUP｜UPT｜AOV`

- 淨值＝總值扣除退貨
- 依月份**降序**排列（最新在上）

## 注意事項

- 上傳既有報表可累積歷史資料，同月份會以新資料合併更新
